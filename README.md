# HUDmentar — downloads

Installers for **HUDmentar**, the telemetry HUD for GoPro karting videos.

Download the latest version from **[hudmentar.com](https://hudmentar.com)** or from the
[Releases](../../releases/latest) page of this repository.

| System | File |
|---|---|
| Windows 10/11 (64-bit) | `HUDmentar-<version>-windows-x64.exe` |
| macOS (Apple silicon) | `HUDmentar-<version>-macos-arm64.dmg` |

The app checks the latest release here and offers to update itself.
This repository only holds the built installers — the source code is not published here.

---

Instaladores do **HUDmentar**. Baixe a versão mais recente em [hudmentar.com](https://hudmentar.com)
ou na página de [Releases](../../releases/latest). O app verifica a última release aqui e se atualiza sozinho.
